# CodeSpark — IT-школа для детей

Статический сайт школы программирования для детей 7–16 лет.

## Страницы
- `index.html` — главная
- `courses.html` — курсы и расписание
- `about.html` — о школе
- `contacts.html` — контакты и форма записи

## Запуск
Откройте `index.html` в браузере. Сборка и сервер не требуются.

## Адаптивность
Сайт адаптирован для телефонов и планшетов через CSS media queries. Подробности: [RESPONSIVE-ISSUES.md](RESPONSIVE-ISSUES.md).
